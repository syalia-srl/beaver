from beaver import BeaverDB, Document

import threading
from beaver import BeaverDB

db = BeaverDB("app.db")
chat = db.channel("chat")

def listen():
    for msg in chat.listen():       # any process with app.db can listen
        print("got", msg.payload)
        break

t = threading.Thread(target=listen); t.start()
chat.publish({"from": "ana", "text": "hello"})
t.join(timeout=5)
got {'from': 'ana', 'text': 'hello'}

The file is standard SQLite: open it with any SQLite tool. Python's own sqlite3 module reads all its tables.

Grows with you

Start with a script. Keep the file.

1A script

Open a file and use it. The same API exists as async, with await.

db = BeaverDB("app.db")
2Many processes

Workers share app.db: a queue hands out jobs, a lock keeps one-at-a-time work, a channel tells the others.

jobs = db.queue("jobs")
3The shell

Read and write dicts, lists, queues and logs from the command line.

beaver --db app.db dict config get theme
4Over the network

Serve the file over REST and connect with the same API. Dicts, lists, queues and logs today.

beaver serve --db app.db --api-key "$KEY"beaver.connect(url, api_key=key)Deployment guide →
Always start beaver serve with --api-key. Without it the server has no authentication, so keep it on 127.0.0.1 (the default).
What's in the box

Twelve tools, one handle.

DictsKey-value with namespaces and per-key TTL. ListsPush, pop, prepend, insert, slices. QueuesPriority queue shared across processes. LogsTime-indexed entries, range queries, a live view. DocumentsFull-text search on SQLite FTS5, plus fuzzy matching. VectorsNearest neighbours, exact or with an LSH index. GraphsLabelled edges, children and parents. BlobsBinary files with JSON metadata. LocksNamed locks across processes, with a TTL. ChannelsPublish and subscribe between processes. SketchesHyperLogLog counts and Bloom filters in fixed space. PydanticAttach a model to any structure for validation.
